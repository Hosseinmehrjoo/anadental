## اجرا
```bash

python3 -m http.server 8124 --directory site
# سپس: http://127.0.0.1:8124/
```

## چه چیزی عوض شد نسبت به اصل
- URLهای `https://arameshdental.com/` برای دارایی‌های صفحهٔ اصلی به مسیر نسبی محلی تبدیل شدند
